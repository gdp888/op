# OPN Chat — Worklog

This folder is the shared working journal for the OPN Chat project (opnchat.net).
It tracks what's been done, what's planned, and what we've learned — so nothing
gets lost between sessions.

## Files

| File | Purpose |
|------|---------|
| [CHANGELOG.md](./CHANGELOG.md) | Reverse-chronological log of every change pushed to production |
| [ROADMAP.md](./ROADMAP.md) | Planned features, ideas, and priorities |
| [DECISIONS.md](./DECISIONS.md) | Architecture & product decisions with rationale |
| [KNOWN-ISSUES.md](./KNOWN-ISSUES.md) | Bugs, tech debt, and things that need fixing |
| [SITE-MAP.md](./SITE-MAP.md) | Current inventory of all pages, tools, and languages |
| [TIPS.md](./TIPS.md) | Dev tips, gotchas, and reusable patterns learned along the way |

## How to use

- **After each work session**: append a new entry to `CHANGELOG.md`
- **When planning next steps**: update `ROADMAP.md`
- **When making a big call**: record it in `DECISIONS.md`
- **When you find a bug**: add it to `KNOWN-ISSUES.md`
- **When you learn something useful**: jot it in `TIPS.md`

This folder is **not** deployed to the website — it's purely for development
tracking. It lives in the repo so it's version-controlled and accessible to
anyone working on the project.
